# Contributing

Issues and pull requests are welcome. Before proposing a change:

1. Open an issue describing the scientific or software need.
2. Preserve public API and schema compatibility unless the change is explicitly
   scheduled for a major release.
3. Add tests for numerical behavior, edge cases, and failure modes.
4. Run `make test` locally.
5. Update documentation and `CHANGELOG.md` when behavior changes.

Contributions must not add confidential data, credentials, or data whose terms
do not permit redistribution. Contributors should disclose material AI
assistance and remain responsible for submitted work.
