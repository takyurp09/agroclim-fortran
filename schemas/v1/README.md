# AgroClim-F schema version 1

The normative field definitions are in `docs/data-contract.md`. Schema v1
contains four named contracts:

- `observations-v1`
- `seasons-v1`
- `results-v1`
- `agroclim-run-manifest-v1`

Minor releases may clarify descriptions or add optional manifest properties.
Removing, renaming, retyping, or changing the meaning of a required field
requires a new major schema version.
