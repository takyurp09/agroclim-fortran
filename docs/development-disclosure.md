Python implementation, tests, and documentation during initial development.

runtime checks, closed-form versus numerical-quadrature tests, independent
cross-language aggregation, explicit failure-mode tests, deterministic
multi-thread comparisons, and reproducible real-data regression outputs.

the scientific assumptions, accepting releases, responding to issues, and
